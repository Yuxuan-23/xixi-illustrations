# Prompt Examples

## 分析讲解卡

```text
Use $xixi-xiaoguang-illustrations 为“用户反馈要先分成体验、功能与性能问题，才能找到真正的优先级”生成一张 4:5 分析讲解卡。
使用“分析讲解卡”模式：西西正指向分析板，小光点亮最关键的问题节点。保留 3-5 个短标签，不要做人物肖像海报。
```

## 系统流程页

```text
Use $xixi-xiaoguang-illustrations 为“把零散内容整理为可表达的观点”生成一张 16:9 系统流程页。
使用“系统流程页”模式：从左到右分为 3 个轻量信息区，小光的光尾串联它们；西西在中间区域整理一张信息卡。标签不超过 6 个短词。
```

## 旅程隐喻图

```text
Use $xixi-xiaoguang-illustrations 为“从不知道怎么开口，到愿意聊”生成一张 16:9 旅程隐喻图。
使用“旅程隐喻图”模式：设计起点、过程和终点，让西西与小光沿着一条有故事感的路线前进；可使用 2-4 张短信息卡。
```

## 判断关系卡

```text
Use $xixi-xiaoguang-illustrations 为“证据不等于结论，先看见关系，才能形成判断”生成一张 4:5 判断关系卡。
使用“判断关系卡”模式：西西观察证据卡，小光用光轨连接到关系装置，再进入结论。不要复刻已有样图的标题、文字或卡片摆放。
```
