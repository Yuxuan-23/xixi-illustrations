# 画面模式与样图

生成时只选一种模式，并只读取该模式列出的样图与 `assets/xixi-face-reference.png`。样图负责视觉语法，不负责照抄主题、文字或构图位置。

## 1. 分析讲解卡

**适合**：问题拆分、原因分析、用户反馈、观察结论、一个明确问题的解释。

**样图**：`assets/西西-小光-米色-讲解图50.png`

**画面语法**：4:5 竖版优先；西西可占约 30%-40%，作为正在指向、思考或记录的分析者；配一块主分析板和 3-6 个节点。小光点亮一个关键问题或节点。

**避免**：西西只是摆拍；分析板只剩空框；整张图堆成长文。

## 2. 系统流程页

**适合**：从零散到清晰、工作流、内容整理、信息处理、多步方法。

**样图**：`assets/ChatGPT Image 2026年7月24日 21_26_47.png`

**画面语法**：16:9 横版优先；画面有 2-4 个轻量信息区，不做机械流程图。西西约占 15%-25%，在中间信息区处理某张卡；小光的金色光尾串联主要区域。允许 3-7 个短标签。

**避免**：把所有区域做成 UI 窗口；箭头和边框过多；西西缩小到看不清。

## 3. 旅程隐喻图

**适合**：从困惑到行动、从灵感到计划、从输入到结果、用户旅程、成长变化。

**样图**：`assets/ChatGPT Image 2026年7月24日 21_56_35.png`

**画面语法**：16:9 横版优先；一个富有故事感的大型物件或两端场景承载旅程，2-4 张信息卡沿路线展开。西西与小光共同走在路线中，小光把方向点亮。允许简短标题与少量卡片文字。

**避免**：只有一个空白大笔记本；路线没有起点或终点；信息卡没有叙事推进。

## 4. 判断关系卡

**适合**：证据与结论、相关与因果、观察与判断、多个信息之间的关系。

**样图**：`assets/master-reference.png`

**画面语法**：4:5 竖版优先；一个核心判断加 3-5 张证据/观察卡，用小光光轨连接。西西约占 20%-35%，处于观察、记录或连接关系的动作中。

**避免**：复刻“证据不等于结论”的标题、卡片内容、对象摆放或配色面积。
